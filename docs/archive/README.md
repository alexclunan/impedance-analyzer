# Archived Plans & Notes — Historical

> ⚠️ **Everything in this folder is historical.** These are the project's older
> planning documents, verification plans, and AI-generated working notes,
> gathered here for reference. **They are not an accurate description of the
> current system** and must not be used as a source of truth — several are
> partially or wholly out of date.
>
> For the current, verified documentation see [`../`](../): the Technical
> Reference Manual (`../reference-manual/`) and the guides (`../guides/`).

Files are stored in `legacy-plans/` with a `<origin>__<name>` naming scheme so
their source is obvious. [`MANIFEST.md`](MANIFEST.md) maps each archived file to
its original location (relative to the repo root) and notes its status.

The archived copies are just that — copies. The originals remain in place in the
repo (e.g. `verification_plans/`) for now; this folder consolidates them into one
place per the documentation plan.
